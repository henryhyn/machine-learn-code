# P2 用户分群与购物篮分析

《讲透经典机器学习》的配套项目 P2。用一家英国在线礼品零售商一年的真实交易，把书里的数据清洗与预处理 (B2)、Pipeline (B5)、聚类 (D1)、关联规则 (D3)、异常检测 (D4) 串起来走一遍。全程没有标签，每一步都要回答“怎么知道做得对不对”。

- 数据：UCI Online Retail (CC BY 4.0)，541909 行交易，2010-12-01 到 2011-12-09，说明见 [data/README.md](data/README.md)。
- 清洗 (`common.clean`)：去掉完全重复的行、没有 CustomerID 的行、非商品行 (StockCode 不以 5 位数字开头：邮费、手工调整、折扣、手续费等)、单价 <= 0 的行；退货行 (发票号以 C 开头) 保留，算消费额时扣掉。
- 评估方式：分群看轮廓系数 + 画像 + 稳定性 + 和 RFM 打分的对比；规则看支持度、置信度、提升度；异常检测靠人工检查和注入已知异常算 AP。

## 运行

在仓库根目录：

```bash
uv run python projects/p2_retail/m1_rfm.py        # 约 1 秒
uv run python projects/p2_retail/m2_kmeans.py     # 约 5 秒
uv run python projects/p2_retail/m3_basket.py     # 约 6 秒
uv run python projects/p2_retail/m4_anomaly.py    # 约 12 秒
```

每个脚本打印过程和结果，并把关键数字写入 `results/<里程碑>.json`。m2–m4 会重新拟合 m2 的分群 (几秒)，各脚本可以单独运行。

## 里程碑

| 里程碑 | 脚本 | 做什么 | 对应章节 |
| - | - | - | - |
| m1 RFM 特征 | `m1_rfm.py` | 清洗；按客户算 Recency (参照日 = 最后一天 +1)、Frequency (购买发票数)、Monetary (扣除退货的净额)；看偏态；五分位 RFM 打分的 2×2 分群作基线 | B2 数据探索与预处理 |
| m2 K-Means 分群 | `m2_kmeans.py` | Pipeline(log1p + StandardScaler + KMeans)；k=2..8 的 inertia 和轮廓系数；k=4 的画像与命名；和 RFM 打分对比 (交叉表、ARI)；初始化稳定性；高斯混合对比；不取对数时离群大客户的影响 | D1 聚类、B5 Pipeline |
| m3 购物篮分析 | `m3_basket.py`、`apriori.py` | “发票 × 商品”布尔矩阵；numpy 实现的手写 Apriori 和规则生成；提升度最高的规则；热门商品让置信度虚高；阈值敏感性；按 m2 的客户群分别挖规则 | D3 关联规则 |
| m4 异常交易 | `m4_anomaly.py` | 发票级特征上的孤立森林和 LOF；人工检查分数最高的 20 张；注入“数量 ×100 / ×10”的录入错误算 AP；contamination 只动阈值 | D4 异常检测、B3 模型评估 |

- 提升度最高的规则都是同系列商品 (Regency 茶盘三色、Poppy's Playhouse 玩具屋、红点纸杯配纸盘)，提升度 47–66。
- 热门商品让置信度虚高：单后件规则按置信度取前 50，后件是前 10 热门商品的有 11 条；按提升度取前 50，0 条。例：JUMBO BAG APPLES 置信度最高的后件是 JUMBO BAG RED RETROSPOT (0.489，提升度 5.6)，提升度最高的是 JUMBO BAG PEARS (0.435，提升度 17.0)。
- 338 个频繁 2-项集的提升度最小 1.28，没有小于 1 的。
- 按客户群分别挖 (min_support=0.02)：“新近低频”群 74.8% 的发票在 2011 年 9 月以后，19 条规则里 57.9% 含 CHRISTMAS；其他群不到 3%。

### m4：异常交易 (18386 张购买发票)

分数最高的 20 张：孤立森林 17 张是只买 1–2 件的小单、3 张是单品批量；LOF 的前两名是两张随后被冲销的真错误 (581483：80995 个纸艺小鸟；556444：60 个单价 649.5 的野餐篮)。

注入异常 (随机 1% 即 183 张发票，一行数量乘以 100 或 10，5 次平均)：

| 方法 | ×100 AP | ×100 复核前 1% 抓到 | ×10 AP | ×10 复核前 1% 抓到 |
| - | - | - | - | - |
| 孤立森林 | 0.182 | 0.178 | 0.020 | 0.026 |
| LOF (n_neighbors=50) | 0.039 | 0.073 | 0.025 | 0.036 |
| 规则：金额 | 0.199 | 0.224 | 0.023 | 0.027 |
| 规则：某行件数 / 该商品常见件数 | 0.563 | 0.439 | 0.063 | 0.074 |

contamination 从 0.001 到 0.05，孤立森林标出的发票从 19 张到 920 张，AP 都是 0.212；`"auto"` 标出 3391 张。

几点观察：

- **清洗**：不扣退货时，客户 12346 一单买 74215 个储物罐又全部退掉，会被当成大客户；用净额后它的消费额是 0。
- **取对数**：RFM 三列强右偏，不取对数时 K-Means 的簇由少数大客户决定，轮廓系数反而更高。轮廓系数只能缩小 k 的范围。
- **规则**：真实数据的强规则多是同系列商品；按提升度而不是置信度排序，才能避开热门商品。分群和时间纠缠在一起时，群的规则可能只是季节。
- **异常检测**：通用检测器找的是“少见”，在批发为主的数据里少见的多是正常单子；知道要找什么时，一条对准它的规则更有效。×10 的录入错误几乎检测不出来。
